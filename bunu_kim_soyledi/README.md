# 🎭 Bunu Kim Söyledi?

Arkadaş grubunuzla veya ailenizle aynı Wi-Fi ağında oynayabileceğiniz, telefonların kumandaya dönüştüğü **Python & FastAPI** tabanlı sosyal parti oyunu.

---

## 🚀 Hızlı Başlangıç

1. Bilgisayarında [Python](https://www.python.org/) kurulu olduğundan emin ol.
2. Bu depoyu indir veya klonla.
3. `run.bat` dosyasına çift tıkla! (Gerekli paketler otomatik kurulacak ve sunucu başlayacaktır).
4. Bilgisayar tarayıcından `http://localhost:8000/host` adresini aç.
5. Aynı Wi-Fi'a bağlı oyuncular ekrandaki QR kodu okutarak telefonlarından katılsın!

---

## 🛠️ Teknolojiler
- **Backend:** Python, FastAPI, WebSockets, Uvicorn
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript
- **Ağ:** Yerel Wi-Fi tespiti ve QR kod üretimi
